Задача 
Дано: личный кабинет на вб+озон+яндекс маркет. 
задача: раз в сутки забор данных по апи остатки + заказы складывать в гугл таблицу. 
1. остаток товаров общий (без разбивки по складам) 
1. 2. заказы за последние предыдущие семь дней + усреднение (пример: заказы от 01.01 - 50шт, от 02.01 150 шт....) (50+150...)/2 =100 в дней. 
Общая логика 
2. столбец А: остаток 1000шт 
3. столбец В: средние заказы 100шт по формуле) 
4. Столбец С: оборачиваемость 1000шт остаток /100 шт заказов = 10 дней всё через средства гугл таблицы.
